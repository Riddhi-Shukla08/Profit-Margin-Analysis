📊 Superstore Sales & Profit Dashboard

📌 Project Overview

The Superstore Sales & Profit Dashboard is a Power BI project created to analyze sales, profit, orders, quantity, discounts, and regional performance using a Superstore dataset.

The dashboard provides interactive visualizations and KPI cards that help understand overall business performance and identify important sales and profit trends.

🎯 Project Objectives

- Analyze overall sales and profit performance
- Track total orders and quantity
- Understand sales performance by category and sub-category
- Compare sales across different regions
- Analyze monthly sales trends
- Identify top-performing products
- Understand the relationship between discount and profit
- Create an interactive and easy-to-understand dashboard

🛠️ Tools & Technologies

- Microsoft Power BI
- Superstore Dataset
- DAX for calculated measures and KPIs

📊 Dashboard KPIs

The dashboard includes the following key performance indicators:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Sales
- Profit Margin

📈 Dashboard Visualizations

The dashboard contains:

- Sales by Category
- Sales by Sub-Category
- Sales by Region
- Monthly Sales Trend
- Profit by Category
- Profit by Sub-Category
- Discount vs Profit
- Top 10 Products by Sales

🎛️ Interactive Filters

Users can interact with the dashboard using:

- Category Slicer
- Region Slicer
- Order Date Slicer

These filters allow users to analyze the dashboard based on specific categories, regions, and date ranges.

💡 Key Insights

The dashboard can be used to identify:

- Which categories generate the highest sales
- Which categories and sub-categories generate the highest profit
- Which regions perform better in terms of sales
- Monthly sales trends and changes
- Top products based on sales
- How discounts may affect profitability

🚀 How to Use

1. Download or clone this repository.
2. Open the ".pbix" file using Microsoft Power BI Desktop.
3. Explore the dashboard using the available slicers and visualizations.
4. Select different categories, regions, or date ranges to analyze the data interactively.
